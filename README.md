# Персонал+

Сайт: https://personalplussite.ru/

## Автоматическое обновление

Публикуются `index.html`, `styles.css`, `script.js`, `favicon.svg`, `robots.txt`, `sitemap.xml` и файлы из `assets/` в ветке `main`. Отправьте commit в `main` или влейте pull request — обновление обычно появится через 1–2 минуты.

Новые изображения и дополнительные ресурсы размещайте в `assets/`. Прочие корневые файлы автоматически не публикуются. Локальные `.env`, API, сервер разработки и README в публикацию не входят.

Перед публикацией проверяются синтаксис JavaScript и наличие локальных ресурсов HTML/CSS. При технической ошибке остаётся предыдущая рабочая версия. Проверки не оценивают правильность текста и дизайна.
